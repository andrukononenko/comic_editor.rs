# 🎭 Comic Editor Pro — создавай комиксы с готовыми персонажами

> «Твой герой — твоя история»

**Comic Editor Pro** — это набор консольных приложений для создания простых комиксов с использованием готовых персонажей.  
Программа предлагает библиотеку персонажей с разными эмоциями, позволяет размещать их на сцене, добавлять реплики и сохранять результат в текстовом или HTML-формате.

## 🚀 Особенности
- 👥 Библиотека готовых персонажей (герой, злодей, робот, монстр, принцесса, рыцарь и др.).
- 😊 Настройка эмоций: радость, грусть, злость, удивление, страх.
- 💬 Добавление диалоговых облаков с текстом.
- 🎨 Создание сцены: выбор фона и позиционирование персонажей (слева, справа, центр).
- 📤 Экспорт комикса в текстовом формате (ASCII-арт) и HTML (для просмотра в браузере).
- 🖼️ Визуальное представление персонажей в ASCII-графике.
- 💾 Сохранение и загрузка проектов из JSON.
- 📋 Режим "слайд-шоу" для последовательного просмотра панелей (где реализовано).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python comic_editor.py`                |
| Go         | стандартная библиотека               | `go run comic_editor.go`                |
| JavaScript | Node.js, `fs`, `readline`            | `node comic_editor.js`                  |
| Java       | стандартная библиотека               | `javac comic_editor.java && java comic_editor` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `serde`, `serde_json`, `rand`        | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby comic_editor.rb`                  |
| PHP        | стандартная библиотека               | `php comic_editor.php`                  |
